# نبض الحيدرية | AL-HAIDARIYA PULSE

نظام أولي لإدارة خدمات مستشفى الحيدرية العام: الصيانة، التنظيف، الأصول، والمخزون.

## التشغيل
- افتح `index.html` مباشرة في المتصفح.
- لا يحتاج إلى خادم أو اتصال إنترنت بعد تحميل الملف.
- البيانات تحفظ محلياً في المتصفح عبر LocalStorage على الجهاز نفسه.

## الوحدات الحالية
- لوحة مؤشرات تحسب الأرقام من السجلات الفعلية.
- بلاغات الصيانة مع النوع والموقع والأولوية والفني والحالة.
- مهام التنظيف حسب المنطقة والوردية والفريق والتاريخ والمشرف.
- سجل الأصول والأجهزة وحالتها الفنية.
- مخزون مواد التنظيف وقطع الغيار مع حد تنبيه.
- تقارير مختصرة قابلة للطباعة.

## ملاحظات مهمة
- هذه نسخة أولية محلية وليست قاعدة بيانات مشتركة بين أجهزة المستشفى.
- لا تُدخل أسماء المرضى أو أرقامهم أو أي معلومات صحية شخصية.
- لا يوجد QR في النظام.
- قبل الاستخدام الرسمي متعدد المستخدمين، يلزم إعداد خادم وقاعدة بيانات وتسجيل دخول وصلاحيات ونسخ احتياطي.
